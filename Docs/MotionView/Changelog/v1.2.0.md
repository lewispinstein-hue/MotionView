# MotionView v1.2.0 Changelog

Source range: `6c69d0fbaf1be8af2c85a1409b3b4c2fc8433d24..1f32cd9ded9067b9d775bb6c939f9307ab92b618`

## Breaking Changes

- MotionView live streaming now targets the bundled MVLib-compatible PROS fork and the newer MVLib data protocol. `v1.2.x` is intended for the updated MVLib release path instead of the older standalone PROS CLI workflow.
- The manual `PROS CLI` executable setting was removed from the app. Live streaming setup now centers on selecting a valid PROS project directory while MotionView launches its bundled runtime.
- Version compatibility guidance was tightened: MotionView `v1.2.x` is the release line for MVLib `v2.0.0` support.

## New Features

- Added bundled MotionView-specific PROS CLI packaging, build, and archive distribution so live streaming no longer depends on a separately installed external PROS CLI executable.
- Added support for the MVLib v2 binary telemetry stream, including mixed raw-terminal decoding, roster sync handling, binary watch packets, waypoint packets, and structured log parsing.
- Changed watch graph comparison with side-by-side latest/sample/avg/min/max stats now showing for the main and comparing graphs.
- Added the `Cmd/Ctrl + R` shortcut for refreshing and resyncing an active livestream session.
- Improved bridge/runtime discovery so updater builds, installed bundles, and target-triple sidecars are found more reliably across platforms.

## Removals

- Removed the settings UI for manually entering or auto-detecting a `PROS CLI` executable path.
- Removed the vendored `chart.umd.min.js` asset and switched the frontend to the packaged Chart.js dependency.
- Removed the old asset sync helper script used for the vendored chart bundle.

## Bug Fixes

- Fixed major live streaming regressions around bridge startup, runtime packaging, and image loading.
- Fixed idle CPU usage in the bundled PROS terminal path.
- Fixed NSIS installation/update issues, including stale sidecar resolution and bundled runtime lookup on Windows.
- Fixed the Windows top bar scrolling bug so overflow state preserves the previous scroll position correctly.
- Fixed live terminal cleanup on Windows by force-closing child processes when needed.
- Fixed noisy terminal output by filtering banner/warning lines that were polluting the MotionView live console.
- Fixed waypoint and decoder handling in the bundled PROS fork so MVLib live streams are parsed correctly.
