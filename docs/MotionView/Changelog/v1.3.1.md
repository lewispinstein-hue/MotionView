# MotionView v1.3.1 Changelog

Source range: `bd6a93edc600ccb53881c2bc1df774bdba77f349..tbd`

## Bug Fixes

- Fixed a Windows production-build stack overflow that could close MotionView immediately after launch.
- Fixed Viewing sidebar tabs not responding to clicks in Windows WebView2.
- Fixed floating information, pinned-watch, and graph panels appearing above modal dialogs instead of behind their blurred backdrops.
- Improved livestream startup feedback when the bridge is available but a PROS project directory has not been configured.
- Hardened live decoding, bridge communication, route imports, and field-image loading against malformed or oversized input.

## Improvements

- Replaced drag-to-scroll controls in the Viewing sidebar and overflowed top bar with natural mouse-wheel and trackpad scrolling; the top-bar scrollbar remains hidden.
- Removed the maximum size limit from floating watch graphs while preserving their minimum dimensions.
- Telemetry is now disabled by default and can be enabled from Privacy settings.
