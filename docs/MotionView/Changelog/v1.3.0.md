# MotionView v1.3.0 Changelog

Source range: `919e915b4465711dcc3d94108c0d7ae88e165fd8..head`

## Breaking Changes

- MotionView JSON export metadata now uses schema version 3 and can include both Viewing mode data and the expanded Planning mode data model. Tools that consume exported MotionView JSON should account for the new `planned-path`, `planned-export-template`, `planned-objects`, and `planned-nodes` sections.

## New Features

- Added zooming support to watch graphs, including mouse-wheel time-range zooming, preserved graph ranges, draggable/resizable graph panels, and comparison-series stats.
- Major Planning mode refactor with reusable planning objects, methods, and timeline nodes that can be placed between waypoints.
- Added Planning mode export support, including editable export templates, generated method blocks, clipboard export, and JSON export for planned paths, objects, methods, and nodes.
- Added the unified Export modal for Viewing mode, Planning mode, or combined exports, with filename sanitization, export destinations, custom-folder support, validation, and success feedback.
- Added route metadata viewing and "Apply Run Settings" support for imported MotionView JSON files.
- Added smart path importing for newer MotionView route exports and improved detection of files that contain viewing, planning, or combined route data.
- Added Override field assets for the 2026-2027 V5 and VEX U seasons.
- Added the "Show previous years' fields" setting so older season fields can be hidden from the field selector.
- Added automatic demo route loading after upgrading from an older app version.
- Added a planning path overlay in Viewing mode so planned waypoints and placed planning nodes can be reviewed alongside recorded or live data.
- Added a disconnect message in the Live window when the connected device drops during terminal streaming.
- Added more telemetry events for app load/exit, livestream metrics, planning actions, template changes, timeline node edits, and JSON exports.
- Changed Planning Mode panning to work anywhere with click + drag
- Added Vex IQ Level Up fields
- Added Competition Selector to show only relevant fields

## Improvements

- Updated the bundled MotionView PROS CLI path to use a dedicated terminal entry point with cleaner headless logging and warning suppression.
- Reworked PROS terminal startup around a buffering-friendly pipe-first flow with PTY fallback, better stale-process cleanup, and clearer bridge diagnostics.
- Improved bundled runtime discovery and executable permission handling for extracted `motionview-pros` builds.
- Improved Planning mode editing with waypoint-specific speeds, selected-waypoint controls, object/method management, drag/drop timeline placement, node highlighting, and tooltips.
- Updated the getting-started demo route to include Planning mode data.
- Updated export templates and made waypoint handles scale more proportionally.
- Updated help-menu links to point at the MotionView GitHub repository and published docs.
- Expanded build targets from the Windows NSIS installer target to all configured Tauri bundle targets.
- Updated app package metadata and version fields to `1.3.0`.
- Switched project to TypeScript
- Made graph automatically resync when live streaming after zooming in/out

## Removals

- Removed the old auxiliary window-state persistence commands and file path used by the previous floating-window implementation.
- Removed the standalone Planning playback speed setting; waypoint speed now controls Planning mode playback behavior.
- Removed the old Tauri library crate declaration that was no longer needed by the app package.

## Bug Fixes

- Fixed `Cmd/Ctrl + Q` and app quit handling so MotionView now runs its frontend exit path, records telemetry, saves state, persists settings, and then finalizes the native quit.
- Fixed cases where saving could be skipped during quit by routing native quit requests through the frontend shutdown handler.
- Fixed optimized-build SVG icon loading by consistently using resolved sprite URLs and relative asset references.
- Fixed live terminal cleanup after serial disconnects and reduced noisy traceback/warning lines in the Live window.
- Fixed raw-stream disconnect handling so MotionView reports a user-facing disconnect instead of leaving the terminal in a broken state.
- Fixed stale PTY reader/file-descriptor state after terminal restarts.
- Fixed planning path/node rendering issues in the Viewing overlay and improved spacing of placed planning nodes.
- Fixed route import edge cases where files with only planning data or mixed MotionView export data were not handled cleanly.
