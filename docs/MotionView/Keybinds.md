# Keybinds

Keybinds for MotionView

| Context | Keybind | Action |
| --- | --- | --- |
| Global | `Cmd/Ctrl + 1` | Switch to Viewing mode |
| Global | `Cmd/Ctrl + 2` | Switch to Planning mode |
| Global | `Cmd/Ctrl + Shift + K` | Clear everything (field + plan) |
| Global | `Cmd/Ctrl + Shift + B` | Toggle the active mode's right sidebar |
| Global | `Cmd/Ctrl + M` | Toggle the active mode's timeline |
| Global | `F` | Fit/reset field position |
| Global | `T` | Toggle Floating info panel |
| Viewing | `Space` | Play/Pause playback (or toggle Auto-follow Head when live-connected) |
| Viewing | `Cmd/Ctrl + O` | Open file selector |
| Viewing | `Cmd/Ctrl + K` | Clear Viewer |
| Viewing | `Cmd/Ctrl + B` | Toggle the left sidebar |
| Viewing | `Cmd/Ctrl + S` | Start/stop live streaming |
| Viewing | `Cmd/Ctrl + R` | Refresh & sync livestream (if streaming) |
| Viewing | `P` | Toggle Planned Overlay |
| Viewing | `G` | Toggle Floating Graph |
| Viewing | `←` / `→` | Step to previous/next pose |
| Planning | `Space` | Play/Pause planning simulation |
| Planning | `Shift + click` | Select multiple waypoints or nodes |
| Planning | `Delete` / `Backspace` | Delete selected waypoint(s) |
| Planning | `←` / `→` / `↑` / `↓` | Nudge selected waypoint(s) |
| Planning | `Shift + ←/→/↑/↓` | Nudge selected waypoint(s) by 5× step |
| Planning | `E` | Open the edit menu of the selected waypoint, node, or method |
| Planning | `Cmd/Ctrl + Enter` | Save and close modal |
| Planning | `Cmd/Ctrl + Z` | Undo |
| Planning | `Cmd/Ctrl + Shift + Z` | Redo |
| Planning | `Cmd/Ctrl + K` | Clear planned path |
